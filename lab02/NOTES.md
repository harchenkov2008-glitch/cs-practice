## Git и GitHub - в чем различие 
**Git** - распределенная система контроля версий. Это программа, которая работает локально и хранит всю историю проекта в папке '.git'.
**GitHub** - облачный сервис для хостинга Git-репозиториева. он не заменяет Git, а лишь хранит копию репозитория и добавляет соц функции: pull request, issues, code review, CI и т.д.
