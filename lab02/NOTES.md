Первый коммит.
рабочая папка (working directory) — где ты редактируешь файлы;
индекс (staging area) — куда ты добавляешь изменения перед коммитом (git add);
коммит — сохранённая «точка» истории с изменениями.

Git vs GitHub
Git — это локальная система контроля версий на твоём компьютере.
GitHub — это удалённый хостинг для хранения репозиториев и совместной работы.
git diff - эта команда показывает разницу между рабочей папкой и индексом (то, что ты ещё не добавил через git add)
git diff --staged - это показывает разницу между индексом и последним коммитом (то, что уйдёт в коммит)

"Использованные команды"
git status — показывает состояние: какие файлы изменены, какие добавлены в индекс, какая ветка активна.
git diff — разница между рабочей папкой и индексом.
git diff --staged — разница между индексом и последним коммитом.
