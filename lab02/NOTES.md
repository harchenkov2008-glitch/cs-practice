Рабочая папка - это папка, в которую я скопировала файлы и редактирую их. Индекс - это некий черновик, в который я вношу свои изменения, которые позже войдут в коммит(снимок). Коммит - это список изменений, кторые я фиксирую в своем проекте.
Различие между Git и GitHub. Git - это система контроля версий, это своего рода интрумент со своими командами, с помощью котрых можно удобно взаимодействоват с проектом локально у себя на компьютерет( даже без интернета). GitHub - это веб-плтформа со своим интерфейсом, на которой храняться все репозитории. 
Различия между git diff и git diff -- staged. git diff - сравнивает индекс(черновик) и текущие изменения в файле. git diff --staged - сравнивает два индекса (передыдущий с текущим).
"Использованные команды"
git status - показывает состояние рабочего каталога и индекса. git diff - сравнивает индекс(черновик) и текущие изменения в файле. git diff --staged - сравнивает два индекса (передыдущий с текущим).
