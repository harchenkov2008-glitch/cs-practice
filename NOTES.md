отличия и значения git diff от git show и git log



git log --oneline --stat - показывает историю изменений проекта в сжатом и наглядном виде. (как будто смотрим фото и подпись к нему, без подробностей)



git diff HEAD\~2 HEAD -- lab03\\calc.py - показывает разницу в файле между текущим состоянием и тем, что было два коммита назад. т.е. по сути мы видим наш изначальный первый ввод с суммой



git show HEAD\~1 - показывает подробную информацию одного определенного коммита, в нашем случае история предпоследнего.



git log -S"def" --oneline -- lab03/calc.py - ищет в истории коммитов изменения, которые производились со словом "def" ( оно или появлялось или исчезало) и кратко показывает эти изменения. в нашем случае в командной строке мы видим пустоту, т.к. у нас нет этого слова.



git blame lab03/calc.py - показывает, кто и когда в последний раз менял каждую строчку в файле.



в чем отличия

git diff — показывает разницу между двумя состояниями (например, коммитами). не показывает историю.

git show — показывает один конкретный коммит целиком. все данные о нем и изменения.

git log — показывает историю коммитов, а не содержимое изменений.
